Разбор правил алгоритма Маркова

Содержит статические методы для разбора одной строки и для чтения всех правил из стандартного ввода.

Считывает правила из стандартного ввода

Каждое правило вводится на отдельной строке, ввод завершается пустой строкой.

Преобразует строку в правило

Формат строки: "левая->правая" для обычного правила и "левая->.правая" для заключительного. Строка должна содержать "->".
